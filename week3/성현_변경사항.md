# B 변경사항

## 담당 범위
`train_language_velocity.py` + `configs/` — 학습 파이프라인 + 하이퍼파라미터

---

## 변경 파일 목록

| 파일 | 변경 내용 |
|------|-----------|
| `train_language_velocity.py` | LR 스케줄러 추가, 축별 오차 평가, 로그에 현재 lr 출력 |
| `configs/week3_siglip_velocity.json` | training_steps 1500→2000, weight_decay 추가, lr_scheduler 설정 |

---

## 상세 변경 내용

### 1. LR 스케줄러 (CosineAnnealingLR)

**DEFAULT_CONFIG에 추가:**
```python
"lr_scheduler": "cosine",
"lr_min": 1e-5,
```

**학습 루프에 적용:**
```python
scheduler = CosineAnnealingLR(optimizer, T_max=training_steps, eta_min=lr_min)
# 매 step마다:
scheduler.step()
```

학습 초반에는 lr=0.001로 빠르게 수렴, 후반에는 lr=1e-5로 줄어들며 fine-tuning.

---

### 2. 축별 오차 평가 (evaluate 함수)

**변경 전:**
```python
metrics = {"mse": ..., "mae": ..., "max_abs_error": ...}
```

**변경 후:**
```python
metrics = {
    "mse": ..., "mae": ..., "max_abs_error": ...,
    "mae_vx": ...,   # 전진 속도 오차
    "mae_vy": ...,   # 횡방향 속도 오차
    "mae_yaw": ...,  # 회전 속도 오차
}
```

어느 축에서 오차가 큰지 파악 가능 → failure case 분석에 활용.

---

### 3. 학습 로그에 현재 lr 출력

**변경 전:**
```
[TRAIN] step=0100/1500 loss=0.00012345
```

**변경 후:**
```
[TRAIN] step=0100/2000 loss=0.00012345 lr=9.51e-04
```

---

### 4. 하이퍼파라미터 튜닝 (configs/week3_siglip_velocity.json)

| 파라미터 | 변경 전 | 변경 후 | 이유 |
|----------|---------|---------|------|
| `training_steps` | 1500 | 2000 | 스케줄러 활용해 더 충분히 학습 |
| `weight_decay` | 0.0 | 1e-4 | 과적합 방지 |
| `lr_scheduler` | (없음) | "cosine" | 수렴 안정성 향상 |
| `lr_min` | (없음) | 1e-5 | 스케줄러 최솟값 |
