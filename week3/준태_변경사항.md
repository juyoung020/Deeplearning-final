### 1. `demo.py` — Week 3 CLI 인수 추가

Week 3 language model을 시뮬레이터에서 사용하기 위한 인수 3개를 추가했다.

```python
parser.add_argument("--go2-physics-language-model-checkpoint", default=None,
    help="Week 3 checkpoint for text -> velocity MLP inference.")
parser.add_argument("--go2-physics-language-model-device", default="auto",
    help="Device for Week 3 language model inference: auto, cpu, cuda, cuda:0, ...")
parser.add_argument("--go2-physics-language-command-duration", default=1.0, type=float,
    help="Seconds to apply each Week 3 predicted velocity command.")
```

| 인수 | 기본값 | 설명 |
|------|--------|------|
| `--go2-physics-language-model-checkpoint` | None | Week 3 학습된 MLP checkpoint 경로 |
| `--go2-physics-language-model-device` | auto | 추론 디바이스 (auto/cpu/cuda) |
| `--go2-physics-language-command-duration` | 1.0 | 커맨드 1개당 실행 시간(초) |

checkpoint를 명시적으로 지정할 수도 있고, 지정하지 않으면 `go2_physics_teleop.py`에서 자동 감지한다.

### 2. `go2_physics_teleop.py` — 학습된 모델 자동 감지 버그 수정

**증상:**
```
Command: move forward 100cm
[WARN] Rejected command: unsupported command. Use "move forward <meters>", ...
```

`--go2-physics-language-model-checkpoint` 플래그 없이 실행 시 Week 2 규칙 기반 `LanguageVelocityCommander`가 실행되어 학습된 모델이 사용되지 않는 문제.

**원인:**

`LearnedLanguageVelocityCommander` 내부에 기본 checkpoint 경로 감지 코드가 있었지만, 실제 분기 조건은 그 바깥에 있어서 checkpoint가 없으면 `LearnedLanguageVelocityCommander` 자체가 생성되지 않았음.

```python
# 문제가 된 코드
language_model_checkpoint = getattr(args, "go2_physics_language_model_checkpoint", None)
if language_model_checkpoint:
    language_commander = LearnedLanguageVelocityCommander(...)  # ← checkpoint 없으면 안 들어옴
else:
    language_commander = LanguageVelocityCommander(...)  # ← Week 2 규칙 기반 실행됨
```

**수정 내용:**

분기 조건 앞에서 기본 checkpoint 경로를 먼저 감지하도록 이동:

```python
# 수정 후
language_model_checkpoint = getattr(args, "go2_physics_language_model_checkpoint", None)
if not language_model_checkpoint:
    default = os.path.join(os.path.dirname(os.path.abspath(__file__)),
                           "checkpoints", "language_velocity_mlp.pt")
    if os.path.exists(default):
        language_model_checkpoint = default  # ← 자동으로 학습된 모델 사용

if language_model_checkpoint:
    language_commander = LearnedLanguageVelocityCommander(...)  # ← Week 3 모델 실행
else:
    language_commander = LanguageVelocityCommander(...)         # ← checkpoint 없을 때만
```

**결과:**

`checkpoints/language_velocity_mlp.pt`가 있으면 플래그 없이도 자동으로 Week 3 학습 모델이 실행됨.

```
Command: move forward 100cm      ← 이제 학습 모델이 처리
Command: go forward 50cm         ← paraphrase도 처리 가능
Command: rotate left 30 degrees  ← 유사 표현도 처리 가능
```

### 3. `configs/week3_siglip_velocity.json` — 데이터셋 11개 → 46개 확장

과제 명세 기준 11개 command만으로는 학습은 되지만 paraphrase(유사 표현)에 대한 일반화가 부족했다. 같은 의미의 다양한 표현과 backward 이동 데이터를 추가해 46개로 확장했다.

**추가된 내용:**

| 추가 유형 | 예시 | 개수 |
|-----------|------|------|
| Forward paraphrase | go forward, walk forward, advance | +9개 |
| Backward 전체 | move/go backward, reverse, back up | +11개 |
| Turn paraphrase | rotate left/right, spin left/right | +9개 |
| Stop paraphrase | halt, stay, don't move | +3개 |
| 거리 추가 | 25cm / 75cm / 1m 계열 확장 | 포함 |

**변경 전 (11개):**
```
move forward 25/50/75cm/1m (4개)
turn left 15/30/45 degree (3개)
turn right 15/30/45 degree (3개)
stop (1개)
```

**변경 후 (46개):**
```
Forward  : move/go/walk forward + advance  (14개)
Backward : move/go backward + reverse + back up  (11개)
Turn Left : turn/rotate/spin left  (8개)
Turn Right: turn/rotate/spin right  (8개)
Stop : stop/halt/stay/don't move  (4개)
```

**학습 결과 비교:**

| | 11개 데이터 | 46개 데이터 |
|--|------------|------------|
| 학습 MSE | ≈ 0 | ≈ 0 |
| paraphrase 일반화 | 불안정 | 안정 |
| backward 지원 | 없음 | 있음 |
